# AntiSuspended

Переносимый скрипт для Linux: отдельные локальные профили Claude Desktop и
Claude Code, региональные настройки по выходному IP, проверка установки и откат.
Нужен Python 3.9 или новее. Дополнительные Python-пакеты и sudo не нужны.

## Запуск

Скачай скрипт и открой меню одной командой:

```sh
curl -fsSL https://raw.githubusercontent.com/narezy/AntiSuspended/main/claude-profile.py -o claude-profile.py && python3 claude-profile.py
```

Команда сохранит `claude-profile.py` в текущую папку и запустит его.
После настройки меню можно открывать командой `claude-profile-manager`.

Первый экран показывает, настроены ли профили и что делать дальше.
Если всё готово, открой обычный ярлык Desktop или введи `claude` в новом
терминале. Для первой настройки выбери `3`, затем Enter. Для проверки сети
выбери `2`, затем Enter. Без интерактивного терминала скрипт показывает статус.

В полноэкранном меню: стрелки или Tab выбирают действие, Enter выполняет его,
PgUp/PgDn прокручивают отчёт, q или Esc закрывают меню. Цифры 1–7 выбирают
соответствующий пункт. Во время операции виден статус; результаты остаются
в панели результата с пояснением следующего шага. При выборе страны можно ввести её двухбуквенный код.
Клавиша d открывает подробности: в обзоре это проверки по группам и локальные ID,
в проверке IP это источники и технический отчёт, после настройки это полный вывод операции.
Перед новым профилем и откатом появляется подтверждение с выбранной по умолчанию отменой.

Зелёный означает готовую локальную настройку, жёлтый означает недостаток
сведений, красный означает проблему. Смысл также написан текстом.
В терминалах с 256 цветами используется отдельная палитра, фон остаётся
пользовательским. Переменная NO_COLOR отключает цвет. Интерфейс перестраивается в узком окне.
Для скринридеров, минимальных терминалов или обычного текстового меню:

```sh
python3 claude-profile.py --plain
```

Быстрые команды:

```sh
python3 claude-profile.py status
python3 claude-profile.py ip
python3 claude-profile.py apply
python3 claude-profile.py repair
python3 claude-profile.py restore
```

`apply` включает автоматический выбор региона. Это обращение к внешнему
сервису определения IP. `status` работает локально и не делает сетевых запросов.

При необходимости добавь каталог команд в PATH и открой новый терминал:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

После настройки обычные команды `claude`, `claude-desktop` и ярлыки Desktop
используют выбранный профиль. Исходные программы не патчатся. Прямой запуск
исходного бинарника по абсолютному пути может обходить настройки менеджера.
Само меню после установки также открывается командой `claude-profile-manager`.

## Регион по IP

При запуске через обёртку скрипт запрашивает геолокацию текущего выходного IP:

- Германия: `Europe/Berlin`, `de_DE.UTF-8`, `de-DE`.
- Нидерланды: `Europe/Amsterdam`, `nl_NL.UTF-8`, `nl-NL`.
- Для стран с несколькими часовыми поясами используется пояс конкретного IP.

Для геолокации используется ipwho.is; если задан IPAPI_IS_KEY, используется
ipapi.is. При обычном запуске клиента выполняется один запрос геолокации.

Для многоязычных стран предусмотрен один явно заданный языковой шаблон.
Например, Швейцария использует немецкий, Бельгия использует нидерландский.
Страна IP не определяет язык пользователя. Если шаблон не подходит, используй
ручной регион или поправь таблицу `REGIONS` в скрипте.

Ручной режим без сетевых запросов при запуске:

```sh
python3 claude-profile.py apply --country NL
python3 claude-profile.py apply --country DE
```

Часовой пояс и язык задаются только процессам клиентов. Системные часы,
системный часовой пояс, MAC-адреса, machine-id ОС, серийные номера и VPN
скрипт не меняет. Он также не меняет User-Agent, Canvas или WebGL.

Если выбранная локаль отсутствует, скрипт пытается собрать её локально
через `localedef`. Для этого в дистрибутиве должны быть исходники локалей.
Если это невозможно, используется `C.UTF-8` с предупреждением; язык Desktop
задаётся отдельно. Один из десяти пунктов проверки тогда не пройдёт.

Если API недоступен, запуск продолжается с последним сохранённым регионом
и предупреждением. Изменения применяются к новым процессам. Для смены региона
Desktop полностью заверши уже работающий клиент, затем открой заново.
Никакая смена страны автоматически не создаёт новый профиль и не сбрасывает ID.

## Проверка сети

```sh
python3 claude-profile.py ip
```

Без ключа сравниваются два HTTPS API: ipwho.is для IP, региона и провайдера;
IPQuery для отметок хостинга, VPN, прокси и Tor. Сведения объединяются только
если оба сервиса видят один IP. Расхождение адресов или регионов выводится
отдельным сообщением. Если поле не вернулось, выводится «нет данных».

Показанный индекс риска IPQuery является оценкой самого провайдера по его
правилам. Это не вероятность блокировки и не рейтинг доверия Claude.
При неполной записи сети числовой индекс не показывается. Для источников и технических
ограничений используй d в интерфейсе или команду `ip --details`.
Отдельная история жалоб может быть недоступна.

Для сравнения можно явно выбрать другой источник:

```sh
python3 claude-profile.py ip --provider ipwho.is
```

У бесплатного ipwho.is обычно есть только геолокация и сведения о провайдере,
без признаков хостинга, VPN или прокси. Данные разных баз могут расходиться.

Для альтернативного расширенного отчёта можно получить личный ключ ipapi.is и перед запуском
задать переменную окружения `IPAPI_IS_KEY`. Скрипт отправляет ключ в теле HTTPS
запроса, не сохраняет его в файлах, не печатает и убирает из окружения запускаемого
клиента. Никогда не встраивай личный ключ в распространяемую копию.

Расширенный отчёт показывает отдельные признаки сети. «Сеть интернет-провайдера»
не доказывает домашнее подключение. «Нет отметки» означает отсутствие отметки
в конкретной базе, а не отсутствие VPN, жалоб или риска. Универсальный балл
доверия IP не рассчитывается.

API определения IP получает адрес, с которого пришёл запрос. При разделении
маршрутов, прокси, разном использовании IPv4/IPv6 или VPN для отдельных приложений
он может отличаться от адреса, который видит Claude. Скрипт не проверяет маршрут
до серверов Anthropic и не обещает обход географических ограничений.

Документация сервисов:

- https://ipquery.io/developers/api
- https://ipquery.io/glossary/risk-score
- https://ipwhois.io/documentation
- https://ipapi.is/developers.html

У сервисов есть лимиты и условия использования, которые могут измениться.
Скрипт не выполняет автоматические повторные запросы после ошибок API.

## Что означает оценка из 10

Это количество пройденных проверок локальной конфигурации:

1. Исходный CLI доступен, если он настроен.
2. Исходный Desktop доступен, если он настроен.
3. Каталоги профиля отделены от стандартных.
4. Каталоги закрыты от других пользователей ОС.
5. Обёртки целы и доступны через PATH.
6. Ярлыки и обработчик ссылок не изменены после настройки.
7. Сохранён существующий часовой пояс IANA.
8. Выбранная системная локаль доступна.
9. В текущем окружении нет явно заданных токенов входа.
10. Доступны резервные копии, установка завершена и код менеджера не изменён.

Отсутствующий клиент не снижает оценку; менеджер настраивает только найденные
клиенты. Статус показывает ID CLI только как результат сравнения с обычным
профилем, без вывода самих значений. На свежем профиле они могут появиться
только после первого интерактивного запуска.

Даже `10/10` не означает анонимность, новый аппаратный отпечаток, доступность
Claude или отсутствие связи между аккаунтами. Аккаунт, оплата, KYC, содержимое
запросов, IP и другие серверные признаки могут связывать сессии.
Фактические переменные всех уже работающих процессов этой оценкой не измеряются.

Для автоматической обработки:

```sh
python3 claude-profile.py status --json
```

## Повторное применение и новые профили

`apply` и `repair` сохраняют текущий профиль, историю, авторизацию и ID.
`repair` восстанавливает созданные менеджером обёртки после их удаления.
Если файл изменён извне, операция останавливается. Для осознанной замены
после просмотра изменений есть `repair --force`.

Новый пустой профиль создаётся отдельной командой:

```sh
python3 claude-profile.py rotate --country DE
```

Без `--country` включается автоматический регион. Предыдущий профиль остаётся
на диске, его путь сохраняется в `previous_profiles` файла `state.json`.
Новая авторизация выполняется пользователем. Скрипт не входит в аккаунты,
не копирует токены, плагины, историю или старые ID в новый профиль.

## Импорт прежней настройки

Если на этом компьютере уже использовалась настройка `claude-isolated`
с отдельными каталогами Desktop и CLI:

```sh
python3 claude-profile.py apply --import-current
```

Она импортируется с сохранением текущего профиля. Старые оболочки и ярлыки
попадают в резервную копию. Откат менеджера возвращает именно состояние
до его применения, которое само могло уже быть изолированным.

## Нестандартная установка

```sh
python3 claude-profile.py apply --country DE \
  --cli-bin /path/to/original/claude \
  --desktop-bin /path/to/Claude.AppImage
```

Поддерживаются стандартные Linux-имена `claude` и `claude-desktop`, а также
символическая ссылка `~/.local/bin/claude`, указывающая на настоящий бинарник.
Если настоящий бинарник лежит непосредственно в `~/.local/bin/claude` обычным
файлом и больше нигде, сначала размести его в отдельном каталоге и укажи путь
через `--cli-bin`. Скрипт не переносит такие файлы автоматически.
Сборки с собственными жёстко заданными путями к профилю могут не поддерживаться.

## Откат, обновления и распространение

```sh
python3 claude-profile.py restore
```

Возвращаются исходные команды, ссылки и ярлыки. Данные обоих профилей сохраняются.
Если после настройки ты редактировал обёртки, сначала проверь изменения;
для осознанной замены есть `restore --force`.

Менеджер сохраняет рабочую копию скрипта в своём каталоге настроек, поэтому
скачанный исходный файл можно переместить. Для обновления запусти `repair`
из новой версии скрипта. После обновлений Claude проверяй `status`: приложения
могут заново зарегистрировать обработчики ссылок или изменить расположение файлов.

По умолчанию настройки и резервные копии находятся в
`~/.config/claude-profile-manager`, профили в
`~/.local/share/claude-profile-manager/profiles`. Учитываются XDG-переменные.
При импорте профиль может оставаться в прежнем каталоге.

Делись только `claude-profile.py`, этим README или исходным архивом.
Не передавай каталоги настроек, резервные копии и профили: они содержат
локальные пути, историю, IP-отчёт и, после входа, данные авторизации.
В распространяемых файлах нет личных путей, ID, IP, токенов или ключей автора.
