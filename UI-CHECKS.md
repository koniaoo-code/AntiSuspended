# Проверка интерфейса 1.2.0

Hard Gate PASS: 34 теста прошли. Проверены все семь действий, размеры 52×18, 80×24, 84×24 и 120×40, а также сообщение для слишком маленького окна. Результаты имеют состояния до запроса, ожидания, успеха, ошибки и отсутствия данных. Цифры и стрелки выбирают пункт, Enter выполняет его, Tab меняет выбор; подтверждение открывается с выбранной отменой. Все строки проверены на выход за размеры терминала. В интерфейсной копии нет длинных тире, вымышленных баллов или обещания анонимности. Реальные снимки установленной версии проверены для обзора и IP-отчёта. Контрастные светлые статусы проверены на фактическом фоне терминала пользователя; при светлом COLORFGBG выбираются тёмные цвета, NO_COLOR отключает цвет. Веб-элементы, изображения и анимации отсутствуют.

Purpose Gate PASS: зелёный отмечает пройденные локальные проверки, жёлтый отмечает недостаток сведений, красный отмечает сбои, голубой выделяет следующий шаг. Значения цветов также написаны словами. Используется отдельная 256-цветная палитра, чтобы пользовательская ANSI-тема не делала состояния одинаковыми. Инверсия отмечает выбор с клавиатуры, один разделитель отделяет навигацию от результата. Фон терминала сохраняется.

Liveliness PASS: направление ENERGY 1 / RHYTHM 2 / MOTION 1. Обзор начинается с вопроса пользователя «что делать сейчас» и конкретной команды либо номера пункта. Иерархию задают статус, следующий шаг и группы проверок. Пояснения под пунктами объясняют их назначение. Пустая строка разделяет смысловые блоки. Результат IP разделён на адрес, регион, сведения о сети и трактовку.

Craftsmanship PASS: 34 теста, включая 18 тестов backend и 16 тестов интерфейса. Проверены: обзор готового профиля → инструкция запуска Desktop/CLI; первая настройка → пункт 3 и Enter; сбой команды → пункт 5 и Enter; неполная база IP → жёлтое «недостаточно данных» без 0/100; положительная отметка VPN → сохраняется; успешное создание профиля → следующий шаг и скрытый полный вывод; d → подробности; NO_COLOR → текстовые статусы сохраняются; четыре семантических цвета → разные пары. Сохранились тесты выборов страны, подтверждений, Unicode, размеров и всех операций backend. Установленная версия прошла десять проверок локальной конфигурации; профили пользователя сохранены.

Клавиатурный проход: обзор → готовность и следующий шаг; 2, Enter → ожидание и живой сетевой результат; d → технический отчёт; 4, Enter → выбор страны, Esc → отмена; 6, Enter → подтверждение, Enter на отмене → профиль сохраняется; 7, Enter → подтверждение, Enter на отмене → установка сохраняется; 1, d → проверки по группам; PgDn/PgUp → прокрутка; q → выход. Полное применение, восстановление, новый профиль и откат дополнительно выполнялись в изолированных временных каталогах тестов.

Веб-требования DOM, CSS, ARIA, hover, изображений и загрузки страницы к curses не применяются. Для скринридеров и терминалов без curses сохранён текстовый режим --plain. Контраст произвольных пользовательских тем нельзя гарантировать; статусы остаются понятными без цвета.
